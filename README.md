## Selected Projects

### OrbTalus (GeoRisk) — environmental risk screening · prototype

I developed the software, with research support from Bia. This geospatial prototype combines a map interface, a FastAPI API and AI-assisted explanations for preliminary environmental risk screening. Coverage depends on available data; outputs are exploratory, not validated predictions or a comprehensive assessment of a property or region. A project overview is available through my portfolio above.

### [Libra](https://github.com/GuilhermeSerafim/libra) — personal library · academic project

My academic implementation of a library application with accounts, book management and ISBN lookup through Open Library. The Spring Boot backend checks book ownership for each user; the React interface integrates sessions and CSRF protection. The repository includes integration tests with Testcontainers and WireMock for database access and external API behavior.

### [Play Senac](https://github.com/GuilhermeSerafim/play-senac) — court booking · team project

A sports-court booking application developed with a team. My contribution focused on the Angular reservation and administration interfaces, forms, responsive layouts and HTTP/RxJS integration. The team's [Spring Boot and MySQL backend](https://github.com/GuilhermeSerafim/play-senac-api) handles booking rules and persistence. The portfolio demonstration uses synthetic data and local operations.

### [Portfolio Health](https://github.com/GuilhermeSerafim/portfolio-health) — demo availability monitor

A Python monitor for public demos, with expiring HTTPS observations and explicit inconclusive states. GitHub Actions publishes the evidence to Pages. Checks cover HTTP behavior; full application functionality remains outside the monitor's scope.
